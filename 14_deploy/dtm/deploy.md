# dtm 部署手册（数据传输服务）

- 版本：v0.1
- 状态：草稿
- 最后更新：2026-10-16
- 作者：DevOps Agent

## 1. 环境依赖

- JDK（与平台协调）。
- RabbitMQ（上行/下行队列）。

## 2. 构建与运行

```bash
mvn clean package
java -jar dtm.jar
```

## 3. 队列与路由

- 上行队列：消费 `ProxyTcp` 发布，发布到 `platform_java` 队列。
- 下行队列：消费 `platform_java` 发布，发布到 `ProxyTcp` 队列。
- 死信队列：异常消息隔离与重放。

## 4. 高可用与削峰

- 多实例消费（同一队列竞争消费）。
- 监控积压（见 `../15_maintain/monitoring.md`）。

## 5. 验证

| 项 | 方法 | 期望 |
| --- | --- | --- |
| 上行转发 | 网关发上行 | 后台收到 |
| 下行转发 | 后台发下行 | 网关收到 |
| 积压 | 监控面板 | 无持续增长 |

## 6. 回滚

- 保留上一版本 jar，重启回滚。
