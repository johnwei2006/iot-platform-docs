## 1. 背景与目标

`web_vue3` 是面向**运营人员**的**管理控制台**，基于 Vue3 + TypeScript + Pinia +
Vue Router + Element Plus + Axios。提供设备监控、配置、报表等管理能力。

> 当前 `2_codes/web_vue3/` 为脚手架 starter（含 `src` 骨架），本需求据此与架构反推。

## 2. 范围

### 含

- 登录与鉴权（对接 `platform_java` API）。
- 设备监控：列表、详情、实时状态、在线/离线。
- 设备配置：增删改查、参数下发。
- 数据报表：统计图表、历史查询。
- 告警看板：实时告警、处理。
- 系统管理：用户、角色、权限。

### 不含

- 设备 TCP 接入与协议细节。
- 终端用户轻量交互（归 `mini_uniapp`）。

## 3. 功能需求（FR）

| 编号 | 描述 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| FR-web-001 | 用户登录与鉴权 | P0 | Token 鉴权，越权被拒 |
| FR-web-002 | 设备列表与分页查询 | P0 | 对接 `platform_java` 设备 API |
| FR-web-003 | 设备详情与实时状态 | P0 | 状态实时刷新 |
| FR-web-004 | 设备配置下发 | P1 | 配置经后台到达设备 |
| FR-web-005 | 数据报表与图表 | P1 | 多维度统计展示 |
| FR-web-006 | 告警看板 | P1 | 告警实时展示与处理 |
| FR-web-007 | 系统/用户/权限管理 | P2 | 运营人员权限可配 |

## 4. 非功能需求

| 编号 | 维度 | 目标 |
| --- | --- | --- |
| NFR-web-001 | 体验 | 首屏 < 2s，交互流畅 |
| NFR-web-002 | 兼容 | 主流浏览器（Chrome/Edge） |
| NFR-web-003 | 安全 | 前端不泄露密钥，接口鉴权 |

## 5. 依赖与接口
