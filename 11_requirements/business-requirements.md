# 平台业务需求（Business Requirements）

- 版本：v0.1
- 状态：草稿
- 最后更新：2026-10-16
- 作者：需求分析师 Agent

## 1. 背景与目标

建设一个**通用 IoT 物联网设备接入与管理平台**，为各类设备提供统一的接入、
管理与运营能力。平台需支撑海量设备长连接接入、可靠上下行报文传输、设备全生命周期
管理，并向运营人员（Web 控制台）与终端用户（小程序）开放。

业务目标：

- **统一接入**：屏蔽设备通信差异，提供稳定的 TCP 长连接接入入口。
- **可靠传输**：上下行报文不丢失、可重发、可追踪。
- **可视运营**：设备状态、数据、告警实时可见、可配置。
- **弹性扩展**：接入层、业务层可独立水平扩展。

## 2. 范围

### 含（In Scope）

- 设备 TCP 长连接接入与会话管理。
- 上行报文解析、校验、持久化、转发；下行指令编码、投递、重发。
- 设备注册、鉴权、状态、元数据管理。
- 设备数据汇聚、规则处理、对外 REST API。
- Web 管理控制台与微信小程序移动端。
- 监控、日志、运维能力（见 `13_test/`、`14_deploy/`、`15_maintain/`）。

### 不含（Out of Scope，本期）

- 具体行业业务算法（如车辆调度、能耗优化）由业务系统叠加。
- 设备固件 OTA（可作为后续扩展）。
- 多租户隔离（后续版本）。

## 3. 业务需求列表（BR）

| 编号 | 描述 | 优先级 | 验收标准 |
| --- | --- | --- | --- |
| BR-001 | 设备通过 TCP 长连接稳定接入网关 | P0 | 单网关支持万级并发连接，断线可重连 |
| BR-002 | 上行报文可靠接收、解析、持久化、转发 | P0 | 报文不丢失，端到端时延 P95 < 1s |
| BR-003 | 下行指令可靠投递并支持失败重发 | P0 | 设备离线可缓存，上线后补发；重发有上限 |
| BR-004 | 设备心跳与在线状态检测 | P0 | 心跳超时判定离线，状态可查询 |
| BR-005 | 设备注册、鉴权与元数据管理 | P0 | 未授权设备拒绝接入；设备信息可增删改查 |
| BR-006 | 设备数据汇聚与业务处理 | P1 | 数据进入后台可供查询与规则处理 |
| BR-007 | 运营人员 Web 控制台 | P1 | 设备监控、配置、报表可用 |
| BR-008 | 终端用户微信小程序 | P2 | 设备状态查看、轻量交互可用 |
| BR-009 | 全链路监控与告警 | P1 | 关键指标可观测，异常可告警 |
| BR-010 | 多环境（dev/test/prod）部署与回滚 | P1 | 各环境独立，发布可回滚 |

## 4. 非功能需求（NFR）

| 编号 | 维度 | 目标 |
| --- | --- | --- |
| NFR-001 | 性能 | 单网关万级并发长连接；上行 P95 时延 < 1s |
| NFR-002 | 可靠性 | 上下行报文持久化 + 重发，不丢失 |
| NFR-003 | 可用性 | 核心服务 ≥ 99.9% |
| NFR-004 | 安全 | 设备接入鉴权、传输加密、接口鉴权 |
| NFR-005 | 可维护性 | 组件解耦、文档齐全、日志规范 |
| NFR-006 | 可扩展 | 接入层/业务层可水平扩展 |
