# web_vue3 运维要点（管理前端）

- 版本：v0.1
- 状态：草稿
- 最后更新：2026-10-16
- 作者：运维 Agent

## 1. 关键指标

- 页面加载时长、JS 错误率、API 调用成功率（前端监控）。

## 2. 常见问题

| 问题 | 处置 |
| --- | --- |
| 页面白屏 | 查构建产物、CDN/域名、控制台错误 |
| API 不通 | 查后台地址配置、跨域、网关 |
| 登录异常 | 查 Token 鉴权与后台 |

## 3. 发布与回滚

- 静态托管切换 `dist/`（见 `../14_deploy/web_vue3/deploy.md`）。
- 前端与后台 API 版本需兼容。
