# platform_java 运维要点（后台业务平台）

- 版本：v0.1
- 状态：草稿
- 最后更新：2026-10-16
- 作者：运维 Agent

## 1. 关键指标

- API QPS、错误率、时延；设备数据落库延迟；规则触发与告警数；DB 连接与慢查询。

## 2. 日志与排查

- 统一日志格式；关注鉴权失败、下行发布失败、DB 异常。
- 链路 ID 透传，便于跨组件追踪。

## 3. 配置项

- 数据库连接、RabbitMQ、Redis（缓存/会话）、外部依赖地址。

## 4. 常见故障

| 故障 | 处置 |
| --- | --- |
| API 错误率高 | 查依赖（DB/MQ）、限流 |
| 上行不入库 | 查消费与 DB 健康 |
| 下行未发出 | 查 MQ 发布与 dtm |
| DB 慢 | 慢查询/索引/扩容 |

## 5. 备份与回滚

- 保留上一 jar；数据库定期备份（见 `../ops-runbook.md`）。
