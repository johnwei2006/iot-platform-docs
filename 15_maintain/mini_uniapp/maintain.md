# mini_uniapp 运维要点（微信小程序）

- 版本：v0.1
- 状态：草稿
- 最后更新：2026-10-16
- 作者：运维 Agent

## 1. 关键指标

- 启动成功率、页面留存、API 成功率、JS 错误率。

## 2. 常见问题

| 问题 | 处置 |
| --- | --- |
| 无法登录 | 查微信授权与后台 Token 兑换 |
| 请求失败 | 查服务器域名白名单（HTTPS）、后台可用性 |
| 审核被拒 | 按微信规范整改后重提 |

## 3. 发布与回滚

- 微信平台可回退已发布版本（见 `../14_deploy/mini_uniapp/deploy.md`）。
- 保留历史构建产物。
