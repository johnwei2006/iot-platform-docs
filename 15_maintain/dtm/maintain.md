# dtm 运维要点（数据传输服务）

- 版本：v0.1
- 状态：草稿
- 最后更新：2026-10-16
- 作者：运维 Agent

## 1. 关键指标

- MQ 积压（backlog）、消费/生产速率、重试次数、死信数量、转发时延。

## 2. 日志与排查

- 关注消费失败、重试、死信；链路 ID 透传。

## 3. 常见故障

| 故障 | 处置 |
| --- | --- |
| 积压增长 | 扩容消费者；查下游健康 |
| 死信增多 | 排查消息格式/下游异常；重放死信 |
| 转发延迟 | 查网络与 MQ 性能 |

## 4. 备份与回滚

- 保留上一 jar；消息本身由 MQ/DB 保障，不需额外备份。
